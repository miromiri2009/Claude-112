# «Оператор 112: Воронеж» — геймдизайн-документ

> **18+.** Все события вымышлены. Реальные службы, люди и организации не имеют отношения к сюжету. Совпадения случайны.

Нарративный экшен-триллер с выездными миссиями (Detroit-style). Игрок — мобильный координатор ЕДДС-112, который первым приезжает на вызов, оценивает обстановку, вызывает службы и до их приезда спасает людей сам. Город гниёт: вызовы исчезают из базы, по городу идёт серия поджогов, а маньяки работают внутри самих служб.

## Коротко

- **Жанр:** нарративный экшен-триллер, выездные миссии, моральные развилки без правильного ответа.
- **Платформы:** PC / PS5 / Xbox Series. Прототип — Godot 4, продакшн — Unreal Engine 5.
- **Длительность:** 12–15 часов на прохождение, 40+ часов на все ветки.
- **9 героев:** 5 положительных, 4 отрицательных. Любой может погибнуть, и смерть не откатывает сюжет, а меняет его.
- **25 миссий** × 9 версий, по одной на героя.
- **27 концовок** (9 героев × 3) плюс скрытая 28-я, «Город без голоса».
