# Реестр сюжетных флагов

Флаги глобальны и переживают смерть героев. Обозначения в миссиях: `ФЛАГ = значение` или `ФЛАГ +1`.

## Главные линии (те, что требует ТЗ)

| Флаг | Значения | Что значит | Где влияет |
|---|---|---|---|
| `ARSONIST` | 0 неизвестен / 1 почерк связан в серию / 2 Стас опознан / 3 Кольцов опознан как «Режиссёр» | Раскрыт ли поджигатель | 3.5, 4.1, 4.4, 5.3, концовки Веры и Кольцова |
| `MAYOR` | 0–3 (улики) | Доказана ли связь Сабурова с ЛХК, «Камелией» и газом | 4.3, 5.3, концовки «Правда» |
| `VERA` | 0 тайна / 1 игрок знает / 2 знают другие герои / 3 Вера сама сдала Стаса | Тайна Веры | 3.5, 5.2, концовки Веры |
| `VERA_COVERS` | 0–5 | Сколько раз Вера скрыла улику против сына | Суд (5.3): при ≥3 её судят как соучастницу |
| `ALINA` | 0 мертва / 1 жива, без доверия / 2 доверяет активному герою / 3 опубликовала часть | Состояние Алины | Доступность концовок «Правда» у всех |
| `PETROV` | 0 неизвестен / 1 подозревается / 2 доказан / 3 арестован / 4 мёртв | Петров | 4.2, 5.3, концовки Петрова, Литвина |
| `ERSHOVA` | 0 / 1 подозревается / 2 «Фильтр» доказан / 3 Мельник доказан / 4 1998 год вскрыт | Ершова | 5.3, 5.4, все концовки |

## Остальные флаги

| Флаг | Значения | Смысл |
|---|---|---|
| `ARCHIVE` | 0–5 фрагментов + `ARCHIVE_PROVEN` (журнал Веры) | Восстановленный «Архив 112» |
| `FILTER` | вкл / выкл / под контролем героя | Состояние «Фильтра» после 4.5 |
| `GROMOV_WITNESS` | 0 / 1 | Громов согласился дать показания |
| `KATYA_SAFE` | 0 / 1 | У Кати Громовой есть деньги на операцию вне схемы |
| `LITVIN_ANGEL` | 0 / 1 подозревается / 2 доказан / 3 признался | Ангел смерти |
| `LITVIN_LIST` | число | Сколько пациентов «отпущено» в течение игры (в т. ч. руками игрока) |
| `KIRILL_LIE` | 0 скрыта / 1 знает Ольга / 2 знает Алина / 3 публично | Ложь 2019 года |
| `KIRILL_DRINKS` | 0 / 1 | Алкоголь Кирилла |
| `DASHA` | 0 мертва / 1 жива / 2 жива и даст показания / 3 скрылась | Дарья Климова (3.3) |
| `LIZA` | 0 / 1 | Лиза Рудь выжила |
| `STAS` | 0 на свободе / 1 арестован / 2 мёртв / 3 сдался | Стас Соколов |
| `SPECTACLE` | 0–7 | Сколько «спектаклей» Кольцова прошло «успешно» (сколько ЧП не предотвращено) |
| `MELNIK_TRUTH` | 0 «суицид» / 1 сомнение / 2 убийство доказано | Смерть Мельника (2.5) |
| `BAGROV` | 0 исчез / 1 даст показания | Администратор «Камелии» |
| `LENYA` | 0 погиб / 1 жив | Водитель МК-112 |
| `CITY` | −100…+100 | Репутация в городе (общая, наследуется на 50 %) |
| `HARD` | 0–100 | Жёсткость прохождения (кровь, жертвы, насилие по вине героев) — влияет на тон эпилога |

## Пороги для концовок (сводно)

- **«Правда»** доступна, если `ALINA ≥ 1` **или** у героя есть «Зенит» / «Монтаж», **и** `ARCHIVE ≥ 3`, **и** `ARCHIVE_PROVEN` **или** `GROMOV_WITNESS = 1`.
- **«Тишина»** доступна всегда (это компромисс), но её «цена» зависит от `CITY` и `HARD`.
- **«Гудки»** (личная / тёмная) открывается флагами, специфичными для героя (см. [07_endings.md](../07_endings.md)).
