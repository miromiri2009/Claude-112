### Ф6. Финал

Отчёт — **протокол**, который написала Ершова, лежит поверх реального хронометража ночи. Несовпадения подсвечены красным (видны игроку, не NPC). Метрика «Расхождение с фактом» (%) — уникальная для Ершовой.

Минута тишины. Ершова одна в квартире, 05:00. Книга открыта. Звук — часы на стене. Затем — первый за 25 лет сон с подвалом (3 с).
