# 5. Система оценки и рангов

## 5.1 Метрики миссии

Показываются в Ф6 каждой миссии на «Отчёте координатора» (у некоторых героев форма отчёта своя — см. версии 3.3).

| Метрика | Как считается | Вес в очках смены |
|---|---|---|
| **Спасено / погибло** | Число людей + имена. Погибший по вине героя (бездействие / выбор) помечен отдельно | +100 за спасённого, −100 за погибшего, −150 за погибшего по выбору героя |
| **Время реакции** | От первого гудка до первого полезного вопроса / действия | 0–10 с: +50 · 10–20 с: +25 · > 30 с: −25 |
| **Точность вопросов** | % «правильных» вопросов в Ф1 (по протоколу: адрес → что случилось → дыхание / сознание → опасность → кол-во пострадавших) | % × 1 |
| **Правильность служб** | Нужные службы вызваны, лишних нет | +20 за каждую нужную, −30 за каждую лишнюю, −50 за пропущенную критическую |
| **Инструкции** | % правильных инструкций (первая помощь, эвакуация, безопасность) | % × 1,5 |
| **Развилки** | Кого спас / кого нет в Ф5 (без «правильного» ответа — очки не начисляются, но выбор записывается в «Летопись») | 0 (только «Летопись») |
| **Смерть героя** | Да / нет, кто новый | Да: −300 к рангу смены, но + «Цена смены» в финале |
| **Сюжетные флаги** | Какие флаги изменены (поджигатель, мэрия, Вера, Алина, Петров, Ершова) | 0 (только «Летопись») |
| **Жёсткость** (`HARD`) | Кровь, жертвы, насилие по вине героев (0–100) | Не очки: определяет тон эпилога и «Голоса» |
| **Усталость** | Шкала 0–100 к концу миссии | > 80: −50 (ошибки от усталости засчитываются отдельно) |

**Специальные метрики героев:**
- Литвин — «Расхождение Прогноза» (белая vs серая цифра, % ошибок).
- Вера — «Координация» (время доезда, потерянная связь).
- Алина — «Вес доказательств» (сумма весов фото).
- Кольцов — «Спасено вопреки / Погибло по сценарию».
- Громов, Ершова — «Правок в журнале» / «Расхождение с фактом».
- Ольга — «Снижено агрессии / риска», «Не спасено, но выслушано».
- Петров — «Совесть» (без подписей).

## 5.2 Оценка миссии

**Очки смены** = сумма весов выше. Буквенная оценка миссии:

| Оценка | Очки | Смысл |
|---|---|---|
| **S** | ≥ 900 | Безупречная работа служб |
| **A** | 700–899 | Отлично |
| **B** | 450–699 | Справился |
| **C** | 200–449 | С потерями |
| **D** | < 200 | Провал службы |

**Важно:** оценка измеряет **работу служб**, а не мораль. Отрицательный герой может получить S, «отпустив» пациента, — и игра покажет это без комментариев. Мораль живёт в «Летописи» и концовках, а не в буквах.

## 5.3 Ранги (сквозные для профиля игрока)

Ранг растёт от суммарных очков всех смен (по всем героям и прохождениям) и открывает бонусы к способностям.

| Ранг | Очки (суммарно) | Бонус | Знак на форме |
|---|---|---|---|
| **Стажёр** | 0 | Подсказки в Ф1 (подсвечен «правильный» вопрос) | Пустой шеврон |
| **Оператор** | 5 000 | Способность +1 с, подсказки выключаются | 1 полоса |
| **Старший** | 15 000 | Способность +2 с, видно 1 скрытую улику на миссию | 2 полосы |
| **Наставник** | 35 000 | Способность +3 с, доступен режим «Архив смен» для всех открытых героев | 3 полосы + звезда |
| **Легенда** | 70 000 + все 9 героев сыграны + 9 концовок | Режим «Без Фильтра» (все звонки — реальные, в 2× больше), альтернативный костюм «Смена 2019» | Значок с цифрами «2:14» |

## 5.4 «Летопись» (то, что не очки)

Отдельный экран из меню паузы: блок-схема в стиле Detroit по каждой миссии — какие ветки открыты, какие выбраны, процент игроков, выбравших каждую (онлайн-статистика, опционально). Плюс:
- **Стена памяти** — все погибшие NPC с деталью.
- **Цепочка смены** — кто кому передал смену.
- **Флаги главных линий** — шкалы: поджигатель, мэрия, Вера, Алина, Петров, Ершова (заполненность без раскрытия спойлеров — «Вы знаете 3 из 5 фактов»).
