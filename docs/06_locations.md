# 6. Локации Воронежа

**Принцип:** улицы, мосты, вокзал, парки и набережные — реальные и узнаваемые. Все учреждения (ЕДДС, ГИБДД, МЧС, скорая, полиция, прокуратура, суд, морг, школа, клуб, завод ЛХК, подрядчики) — **вымышленные**, хотя стоят по реальным адресам. Конкретные номера домов у вымышленных учреждений не совпадают с реальными организациями; при продакшене каждая точка проходит проверку (см. [10_ethics.md](10_ethics.md), 10.5).

## 6.6 Визуальный язык города

- **Палитра:** мокрый асфальт, натриевые фонари (оранжевый), синий проблеск мигалок, зелень пульта ЕДДС. Огонь — единственный тёплый цвет ночи.
- **Звук:** трамвайный звонок (центр), гул фур (мосты), бас из подвалов, колокол храма, сирены оповещения (глава 4). «Слух» Веры строится на реальном звуковом ландшафте города: команда записывает полевые звуки на улицах из этого списка.
- **Время года:** поздняя осень → первый снег (главы 3–4) → весна в эпилоге.
